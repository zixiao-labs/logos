# Logos CRDT Collaboration Enging

This package provides a CRDT-based collaboration engine for Logos Editor. It is designed to be fast, efficient, and easy to integrate with the editor's core functionalities.

It should be the fastest collaborative implementation of CRDT + Lamport clock in the JavaScript world, second only to Zed using Rust (of course, we can't rule out the possibility that we will develop native modules like NAPI-RS or node-gyp C++).
