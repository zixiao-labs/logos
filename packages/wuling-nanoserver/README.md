# Wuling DevOps Workspace Nanoserver

This is a nanoserver image for Wuling DevOps Workspace, Use this when you are using a development container or WSL, without needing to use wuling,zixiaolabs.com's Software as a Service or a self-hosted full Wuling DevOps (of course, if you want to use it with collaboration features, it is still recommended to host the code on github/gitlab/self-hosted Wuling DevOps instance/Wuling DevOps Software as a Service version).


A low-overhead Node.js implementation (compared to the full server version), making development on older computers/MacBook Neos a breeze.
